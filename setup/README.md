# Orca Agent — Setup Guide (Windows 10/11)

> One-shot installer for running the Orca Agent Telegram bot on a
> Windows laptop. Tested on Windows 10 Pro 22H2 and Windows 11.

## 🚀 Quick Start (60 seconds)

**Open PowerShell as Administrator** (right-click → "Run as Administrator"),
then paste this one-liner:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force ; `
iwr -useb https://raw.githubusercontent.com/hermasorca13-stack/Orca-Agent-Unified/master/setup/setup.ps1 | iex
```

The script will:
1. ✅ Check Python 3.11+ and Git (offer to install if missing)
2. ✅ Clone the repo to `D:\ORCA AGENT\Orca-Agent-Unified`
3. ✅ Create a Python venv
4. ✅ Install all requirements (~200 MB)
5. ✅ Create `.env` and prompt for your Telegram bot token
6. ✅ Run the test suite to confirm a clean install
7. ✅ Install a Task Scheduler entry for auto-start on boot
8. ✅ Install a keep-awake watchdog (no sleep when bot is running)
9. ✅ Install a health check (Telegram alert if the bot falls over)

## ⚙️ Task Scheduler entries created

| Task | Trigger | Purpose |
|---|---|---|
| `OrcaAgent` | At logon | Runs the bot in the background |
| `OrcaAgentKeepAwake` | At logon | Prevents sleep while bot is running |
| `OrcaAgentHealthCheck` | Every 5 min | Pings the bot + bridge, alerts via Telegram if down |

All three are created by `setup.ps1` and can be inspected in
`taskschd.msc` (Task Scheduler).

## 🎮 Useful commands

```powershell
# Start / stop the bot
Start-ScheduledTask -TaskName OrcaAgent
Stop-ScheduledTask  -TaskName OrcaAgent

# View live logs
Get-Content "D:\ORCA AGENT\Orca-Agent-Unified\logs\orca.log" -Tail 50 -Wait

# Update the bot from GitHub
git -C "D:\ORCA AGENT\Orca-Agent-Unified" pull

# Restart the bot
Stop-ScheduledTask  -TaskName OrcaAgent
Start-ScheduledTask -TaskName OrcaAgent

# Test the install
cd "D:\ORCA AGENT\Orca-Agent-Unified"
.\.venv\Scripts\Activate.ps1
python -m pytest tests/ --ignore=tests/test_telegram_bot.py -q

# Re-run setup (e.g. after editing .env)
.\setup\setup.ps1
```

## 📱 Setting up the Termux bridge (phone)

After the bot is running, in Telegram send:

```
/termux setup
```

The bot will reply with a JSON config. To make it easier, run on the
laptop (PowerShell):

```powershell
cd "D:\ORCA AGENT\Orca-Agent-Unified"
.\setup\termux_setup.ps1
```

This will print the exact `termux_bridge.json` and the URL/token you
need. Then on your phone (Termux), follow the printed instructions.

## 🔐 Environment variables

The setup script writes a starter `.env` for you. The most important
keys:

| Variable | Required | Purpose |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ yes | The bot's @BotFather token |
| `GITHUB_TOKEN` | optional | For `/gh` self-update commands |
| `OPENAI_API_KEY` | optional | For LLM-powered analysis (has offline fallback) |
| `ANTHROPIC_API_KEY` | optional | Same, for Claude |
| `TERMUX_BRIDGE_TOKEN` | optional | Auto-generated by `termux_setup.ps1` |
| `ORCA_ADMIN_CHAT_ID` | optional | Your Telegram chat_id, for health alerts |

To get your chat_id, message `@userinfobot` on Telegram.

## 🚨 Troubleshooting

### "Running scripts is disabled on this system"
The `setup.ps1` one-liner already includes `Set-ExecutionPolicy Bypass`
but if you run a different script manually, first run:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

### "git is not recognized"
Install Git: https://git-scm.com/download/win
Make sure "Git from the command line" is selected during install.

### "python is not recognized"
Install Python 3.12: https://www.python.org/downloads/windows/
**Tick "Add Python to PATH"** during install.

### Bot starts but doesn't respond on Telegram
1. Check `.env` has the right `TELEGRAM_BOT_TOKEN`
2. Test: `curl https://api.telegram.org/bot<TOKEN>/getMe`
3. View logs: `Get-Content logs\orca.log -Tail 50 -Wait`

### Laptop still goes to sleep
1. Open `powercfg.cpl` → "Change plan settings" → set "Put the computer
   to sleep" to "Never" when plugged in
2. The `OrcaAgentKeepAwake` task only prevents sleep while the bot
   is actively running

### Termux bridge is unreachable from phone
1. Make sure the laptop and phone are on the same WiFi
2. Allow Python through Windows Firewall:
   ```powershell
   New-NetFirewallRule -DisplayName "Orca Bridge" -Direction Inbound -LocalPort 8765 -Protocol TCP -Action Allow
   ```
3. Or use the laptop's IP from `termux_setup.ps1` (not `localhost`)
