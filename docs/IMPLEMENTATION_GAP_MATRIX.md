## ما يمكن استكماله هنا دون اتصال الكمبيوتر

يمكن إضافة موصلات مصادر البيانات، محرك المحافظ، اختبارات الضغط، التقارير، وتكاملات المراقبة داخل المستودع. أضيف القسم 21 كتطبيق تحليلي قابل للاختبار، لكن لا يمكن إثبات التشغيل الدائم أو جودة البيانات الخاصة بحسابات المستخدم أو تنفيذ أوامر حقيقية دون مورد خارجي فعلي.

## ما يتطلب الاتصال المستقبلي

يتطلب الاستكمال المباشر تثبيت الاعتمادات على الكمبيوتر، إعداد خادم دائم، إدخال مفاتيح sandbox في مدير أسرار، فحص كل منصة، تحميل بيانات تاريخية حقيقية، تشغيل الاختبارات الكاملة، ثم الانتقال إلى live فقط بعد تحقق مستقل من الصلاحيات وعدم وجود السحب.
