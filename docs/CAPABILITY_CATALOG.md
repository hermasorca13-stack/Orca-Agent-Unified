# ORCA Max Mouny — سجل استخلاص القدرات

تمت مراجعة الملف المرفق `orca-skills-techniques-strategies.ts` ومقارنته ببنية Python الحالية. الملف المرفق يصف مشروعًا جوالًا مستقلًا بمسارات Expo/React Native وNode/tRPC، بينما مستودع `Orca-Agent-Unified` الحالي هو محرك تداول Python. لذلك لم تُنسخ بنية الجوال أو عقود TypeScript أو واجهاته إلى المستودع؛ ذلك سيكون تكرارًا وتغييرًا غير مطلوب في المعمارية.

## ما أُضيف لأنه مفيد وجديد

| العنصر | القرار | الدليل داخل ORCA |
|---|---|---|
| سجل قدرات قائم على الدليل | أُضيف | `trading_bot/ops/capability_catalog.py` |
| منع التكرار وربط القدرة بملفات إثبات | أُضيف | `validate_catalog` و`find_capabilities` |
| توحيد مفهوم الحالة: منفذ/مضبوط/موثق/مختبر/حاجز | أُضيف كفهرس توثيقي | `Capability.status` |
| حفظ الحدود Paper/no-secrets/review-only في سجل واحد | أُضيف كفهرس غير تنفيذي | سجل القدرات وملفات الخزنة والمخاطر الحالية |
| الإشارة إلى الأحداث متعددة اللغات وسلسلة منشأ البيانات | رُبط بالمكونات الموجودة | القسمان 23 و24، دون إعادة بناء منطق مكرر |

## ما كان موجودًا فلم يُكرر

| العنصر في الملف المرفق | حالته الحالية | قرار الاستخلاص |
|---|---|---|
| Paper-only by default | موجود في Settings ومحرك التنفيذ والاختبارات | لم يُنسخ |
| الفصل بين Paper/Sandbox/Live | موجود في الإعدادات والموصل والخزنة | لم يُنسخ |
| Least privilege وno secrets | موجود في الخزنة وAuditLog وKill-Switch | لم يُنسخ |
| Manifest/checksum/data lineage | موجود في data quality والقارير | لم يُنسخ |
| Defensive parsing وsafe fallback | موجود في مزودي البيانات والجاهزية | لم يُنسخ |
| Layered architecture | موجود في `trading_bot/` بطبقاته | لم يُنسخ كهيكل TypeScript موازٍ |
| Test-driven guardrails | موجود في 40 اختبار ORCA واختبارات regression | لم تُنشأ منظومة Vitest موازية |
| Human review before promotion | موجود في حوكمة الأقسام 20–24 | لم يُكرر |
| Risk disclosure/non-promissory reporting | موجود في الوثائق والتقارير | لم يُكرر |

## ما استُبعد لأنه غير منطبق أو غير مثبت

عناصر Expo/React Native، React Navigation، NativeWind، tRPC، Drizzle/MySQL، OAuth/JWT، SecureStore، AsyncStorage، وشاشات الجوال لا تنتمي إلى مستودع التداول Python الحالي ولا توجد مساراتها داخله. كذلك لم تُستخلص أي استراتيجية تداول جديدة من الملف لأن محتواه يصف هندسة منتج وتوثيق قدرات، وليس دليل أداء أو قواعد تداول قابلة للإثبات. لا يسمح سجل القدرات بتحويل وصف مكتبي إلى claim أداء أو صلاحية Live.

## الضابط

سجل القدرات معرفي وتوثيقي فقط. لا يغير أوزان الاستراتيجيات، ولا يفتح الأسواق، ولا يقرأ الأسرار، ولا يرسل أوامر. أي قدرة مستقبلية لا تدخل السجل إلا مع ملف إثبات واختبار أو حالة `blocked` واضحة.
